BioPhys Lab v2.0 - Android Studio project (NOT a precompiled APK).

1. Install Android Studio with Android SDK Platform 35 and JDK 17.
2. Open this folder in Android Studio and allow Gradle sync.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK location: app/build/outputs/apk/debug/app-debug.apk
5. Transfer app-debug.apk to Android and install it (with your device permission).

The lab is bundled in app/src/main/assets/index.html and runs without network permission. Audio starts after a user tap. This project was generated without an installed Android SDK in the current environment, so it has not been compiled or device-tested.
